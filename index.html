Why bother?

A good FOIA request turns “I wonder” into a traceable search for agency records.

It is especially useful when the thing you are looking for is older, hard to discover, not posted online, or likely to live in internal agency files rather than a public database.

01

Reach beyond the website

Ask for existing SEC records that are not already easy to find in EDGAR, rulemaking pages, enforcement releases, or other public collections.

02

Get a trackable request

A submitted request receives an agency tracking number, creating a concrete record you can follow through acknowledgment, processing, and response.

03

Create reusable research

When releasable records come back, posting them publicly can save the next researcher from having to rediscover the same material alone.

04

Learn from the process

Scope questions, fee decisions, searches, exemptions, and productions all teach future requesters how to frame better requests.

Find something new

Go from curiosity to a records lead.

You do not need to arrive with a finished FOIA request. Start by finding a gap in the public record, narrow it into a record set, then leave a GitHub trail so someone else can improve, file, or follow it.

1

Start in public

Search SEC.gov, EDGAR, rulemaking files, enforcement material, historical releases, and FOIA logs. Write down what exists and what appears to be missing.

Search EDGAR ↗
2

Identify the gap

Turn “I cannot find this” into a concrete hypothesis: a memo, email chain, meeting record, database export, log, attachment, referral, or other existing record may fill the gap.

3

Scope the search

Add dates, names, offices, custodians, document types, matter numbers, releases, or unusual search terms. The goal is a search the agency can reasonably perform.

Use the request builder ↓
4

Put the lead on GitHub

Not ready to file? That is still useful. Open a research lead with what you searched, what is missing, and the record set you think may exist.

Open a FOIA lead ↗
5

File, track, iterate

File a focused request, publish the correspondence, and use the response to decide whether the next step is a narrower search, an appeal, or a new records question.

GitHub workflow

Leave enough context for the next person.

For research leads, include what you already searched and the records you think may exist. For documents, preserve the original file and explain where it fits in the timeline. For site changes, keep the public-facing explanation understandable to someone seeing FOIA for the first time.
